# MySQL 面试八股

## 第一章 索引
### 1. 为什么用 B+ 树
B+ 树矮胖，三层左右就能存千万级数据，磁盘 IO 次数少。对比红黑树、哈希索引的取舍。

### 2. 聚簇索引与二级索引
聚簇索引叶子节点存整行；二级索引叶子只存主键，所以查非索引列要回表。

### 3. 最左前缀与索引失效
联合索引 (a,b,c)，查询从最左列开始才能用上；在索引列上做函数、隐式类型转换会让索引失效。

## 第二章 事务
### 1. ACID 是怎么实现的
原子性靠 undo log 回滚；持久性靠 redo log 刷盘；隔离性靠 MVCC + 锁；一致性是最终目标。

### 2. 四种隔离级别
读未提交、读已提交、可重复读（默认）、串行化。可重复读靠 MVCC 快照实现。

### 3. MVCC 和 ReadView
每行有隐藏的版本链，事务开始时生成 ReadView，据此判断哪些版本可见。

## 第三章 锁与并发
### 1. 锁的粒度
全局锁、表锁、行锁。InnoDB 默认行锁，但没走索引会退化成表锁。

### 2. 间隙锁与临键锁
可重复读下，范围查询会加间隙锁，用来防幻读。

## 第四章 日志与持久化
### 1. redo log 与 binlog
redo log 是 InnoDB 的物理日志，循环写；binlog 是 MySQL Server 层的逻辑日志。

### 2. 两阶段提交
redo log 和 binlog 靠两阶段提交保持一致，先 prepare 再 commit。
