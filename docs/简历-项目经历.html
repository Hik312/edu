版本 A：主推版（AI Agent 岗）

智径 EduPath（个人项目） 2026/09-至今　全栈开发
技术栈：Python、FastAPI、LangGraph、LangChain、MySQL、PostgreSQL、Redis、Ollama（qwen3:8b / deepseek-r1:7b / nomic-embed-text）、Vue3、Vite、Element Plus、ECharts、力导向图、JWT
项目描述
面向计算机与考研知识点的「卡片式学习平台」。把 416 张原理卡片组织成 567 节点 / 2114 边的知识图谱，用 PageRank、Louvain 等图算法做知识点关联与路径规划，用 SM-2 / FSRS / BKT / HLR 四种间隔重复算法做复习排期，并以 LangGraph 编排的 Agent 层支撑 AI 问答与自动造卡。全部依赖本地 Ollama 模型，数据自建。
主要工作：
  1. 知识图谱构建：将 416 张卡片按「学科→章节→主题→卡片」四层建模，沉淀 567 节点 / 2114 边有向图，并维护 234 条先修依赖边；配套实现 PageRank、Personalized PageRank、介数中心性、Louvain 社区发现、最短路径、k-core 共 6 个图算法，为「哪些知识点该先学」「知识点之间怎么走」提供量化依据。
  2. AI 问答 Agent：基于 LangGraph StateGraph + create_react_agent 实现 ReAct 循环，自主决策调用 4 类工具（卡片检索 / 卡片详情 / 关联卡片 / 今日待复习）并可联网补充，回答以 SSE 流式返回；提供 vector + keyword 混合检索，本地 nomic-embed-text 向量索引覆盖全部 416 张卡（4.1MB），实测向量召回能命中关键词检索漏掉的语义近邻卡。
  3. 间隔重复算法选型：独立实现 SM-2、FSRS-4.5、BKT（含四参数拟合）、HLR 四种算法并抽象统一契约；构建仿真评测层，用同一条遗忘曲线 R(t)=2^(-t/h) 对 300 张卡做 365 天排期对拍，两个随机种子结果一致。实测 FSRS 投入产出最优（效率 0.0186，复习次数较 SM-2 少 20%），HLR 期末留存最高（66.5% vs SM-2 的 56.4%）。
  4. 自动造卡流水线：用 LangGraph 编排「文档摄取 → LLM 自主定切分点 → 近重标题去重 → 落盘」四阶段，文档转卡片全流程自动化，替代人工整理。
  5. 存储与鉴权：MySQL / PostgreSQL / Redis 三层存储，每层均实现「装不上就降级」的降级路径并在启动横幅显式告警；鉴权迁移至 PyJWT 零依赖方案（HS256），并将「是否鉴权」的判定标准从读写操作改为「响应是否含个人数据」，修复越权风险。
  6. 前端可视化：Vue3 + ECharts 实现图谱力导向视图，支持学科/主题多级筛选、社区着色、节点邻居展开；修复「图与统计口径不一致」导致社区命名全部失效的问题（15 个社区 13 个显示空），并把邻居展开从固定 1 跳改为「展开到见到卡片为止」，单节点可见卡片数从 0 提升到 129 张。
