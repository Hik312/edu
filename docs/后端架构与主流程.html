依赖方向　接入层 → 业务层 → 算法层 / Agent 层 / 存储层，单向。业务层只算不存、存储层只存不算，两边靠 store/base.py 的契约连起来。算法层不 import 业务层，所以 python -c "import algo.graph" 不起服务就能跑 —— 这是能离线对拍的前提。

三处坑　① x['level'] or 9 会把未标记（0）算成 9，整批新卡被排到「已会」后面；② 方向筛选与 BKT 排序必须写在 items[:limit] 之前，反了等于没筛；③ schedule() 转发时漏传 today，重放历史事件全算成「今天」，逾期天数排序全错。
